# Custom Integrations

| Folder | What it does |
|---|---|
| [EchoSyncTool](EchoSyncTool) | Turns the AIE alarms your LogRhythm SIEM actually raised into replayable LogRhythm Echo use cases, with a coverage report. Also includes a standalone `.llx` reader/writer. |
| [LogRhythm&WindmillIntegration](LogRhythm%26WindmillIntegration) | SmartResponse actions that send alarms to Windmill, Slack, Teams or a generic webhook. |
| [Webhooker2Syslog](Webhooker2Syslog) | A Windows service that receives webhooks and forwards them to LogRhythm as syslog. |
